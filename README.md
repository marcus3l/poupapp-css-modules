# PoupApp — painel financeiro com CSS Modules

Painel de finanças pessoais que reúne saldos de contas, orçamento diário, progresso de economia e transações em uma interface única. Esta versão aplica CSS Modules para organizar os estilos por componente.

## Funcionalidades

- Resumo de contas e saldos
- Indicador de orçamento diário e meta de economia
- Lista de transações com busca
- Interface dividida em componentes reutilizáveis

## Tecnologias

React, JavaScript, Vite e CSS Modules.

## Como executar

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local da aplicação. Para criar a build de produção, execute `npm run build`.

## Contexto

Solução de desafio educacional de React com foco em componentização e estilização modular.
